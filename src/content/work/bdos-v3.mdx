## How it is organized

Source models are YAML. Each one is checked against its schema before anything is built, and the build output is never edited by hand. That rule is the whole point: a document a person can edit freely is a document that will eventually disagree with the system.

Testing and MkDocs integration run in the same pipeline as the models, so a change that breaks the documentation site fails before it merges.
